# v1.1.0 — Tactical Interface and Patch Intel

- Redesigned responsive MW4-inspired graphite/lime interface using fluid CSS sizing and viewport-aware columns.
- Animated focus, hover, loading, navigation transitions with reduced-motion accommodations.
- Added all-weapon 9-goal blueprint strategies with per-slot attachment focus guidance.
- Separate saved loadouts by mode, weapon, and goal; new My Blueprints management page.
- Preserved legacy v1 browser progress and import/export compatibility.
- Source discovery from the official Call of Duty patch hub, with article allowlisting and robust fallback.
- Daily GitHub Actions patch watch now tracks status and handles partial source failures without erasing entries.
- Added new watcher tests, parser tests for 2027, and source-host safety checks.

**Scope:** Strategy preferences are not verified numerical weapon statistics. Patch watcher is best-effort, publisher dependent; weapon roster currently covers the 35 MW4 weapons, not the full legacy Warzone catalog.
